# Virat_Kohli_Performance_Analysis

A comprehensive Power BI dashboard analyzing Virat Kohli's cricket performance across different formats (ODI, T20, Test), opponents, venues, and years.

---

## 📊 Dashboard Overview

![Virat Kohli Performance Analysis](dashboard.jpg)

---

## 💡 Key Features & Metrics Analyzed

* **Key Performance Indicators (KPIs)**:
  * **Total Runs:** ~24K Runs tracked in the dataset
  * **Matches Played:** 516
  * **Average Runs Per Match:** ~46
  * **Career Duration:** 14 Years (2008 – 2022)
* **Format Analysis**: Breakdown of runs across **ODI**, **T20**, and **Test** matches using an interactive donut chart.
* **Opponent & Ground Slicers**: Interactive filters allowing users to analyze performance against specific countries (*Australia, England, Pakistan, etc.*) and at specific venues (*Adelaide, Wankhede, Kolkata, etc.*).
* **Yearly Trends**: Line chart displaying total matches played per year and a pie chart illustrating run distribution by year.
* **Top Performances**:
  * **Sum of Runs by Ground**: Highlights highest scoring grounds (e.g., Mirpur, Wankhede, Adelaide).
  * **Sum of Runs by Opponent**: Visualizes total runs scored against major rival teams.

---

## 🛠️ Tools & Technologies Used

* **Power BI Desktop**: Data transformation, DAX modeling, and visual design.
* **Microsoft Excel**: Source dataset (`Virat_Kohli_Dataset.xlsx`).
* **Power Query**: Data cleaning and schema structuring.
